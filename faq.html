Frequently Asked Questions about GGamerGGuy/Tylerbmusic's GeoFS Addons

How do I install addons?

Using Tampermonkey (recommended):

Step 1: Copy the contents of 'userscript.js' into your clipboard
Step 2: If you haven't already, download Tampermonkey
Step 3: Press the Extensions icon on the toolbar at the top of your browser and click on the icon that looks like a rounded square with two eyes at the bottom, and press "Dashboard"
Step 4: Press the little "+" tab, delete everything in the big text box, paste your clipboard contents into that text box, and press Ctrl/Cmd + S to save it.
Step 5: Open GeoFS, and it should work!

Note: When installing Tampermonkey, you may need to enable Developer Mode inside of the browser's settings, and click "Allow User Scripts" in Tampermonkey's browser settings.

Using Dev Tools:

For each addon, and each time you load or reload GeoFS,
Step 1: Copy the contents of 'userscript.js' into your clipboard
Step 2: Go to GeoFS and press Ctrl+Shift+I (or Cmd+Shift+I on mac). A panel should open.
Step 3: At the top of the panel, make sure "Console" is the selected tab. If it isn't, select it by clicking on it. If you don't see "Console" as an option, click the ">>" or "+" icon, find "Console", and click it.
Step 4: Paste the contents of your clipboard into the console.
Once you've added all addons, close DevTools by clicking the "X" on the top right of the panel.

Using a bookmarklet:

Step 1: Copy the contents of 'userscript.js' into your clipboard
Step 2: Paste it into a bookmarklet maker (This one seems to work well)
Step 3: Add a bookmark to the page you're on (sometimes called a "favorite", depending on your browser) and change the name to be the name of the addon, and the URL to be the bookmarklet maker's output
Step 4: Each time you load or reload GeoFS, click on the bookmarklet.

Why isn't this addon working?

My addons can take up to 30 seconds to load, so try waiting first.
Many addons also have images, audio, models, etc., so a poor internet connection can also add time to load (Taxiway Lights, Taxiway Signs, and Streetlights can take up to three minutes to load, depending on internet connection and airspeed)

If you're using Tampermonkey, when you go to GeoFS, the Tampermonkey icon should have a white number with a red background that indicates how many userscripts are running
If it doesn't have that, check that Developer Mode is enabled and "Allow User Scripts" is enabled.

In rare cases, there can be compatibility issues with other addons. All of my addons were created to work with each other, but sometimes someone else's addon(s) will conflict with mine.
The only known compatibility issue is GeoFS Sky Dolly and GeoFS Livery Selector.

If you've tried everything above, and the addon still isn't working, the addon may have a bug.

How do I report a bug?

In the addon's GitHub page, go to the "Issues" tab and create a new issue.

When reporting a bug, please include:
- A detailed description of what the bug is and how you found it (if I can't recreate the bug, I can't really fix it)
- Your browser (Edge, Chrome, Firefox, Safari, etc.), your operating system (Windows, Mac, Chrome OS, etc.)
- Your GeoFS version number
- Any other relevant details

How do I use this addon?

If the addon has a README.md, refer to that for usage instructions.

Many of my addons use a shared addon menu for settings and customizatinon. To access that menu, go to GeoFS and look for an "ADDON SETTINGS" button at the bottom. Click that button to open a settings panel. From there, you can enable and disable addons, chane settings, and view and change keyboard shortcuts.

If the addon has no README.md and no addon menu, try doing what you think it does (e.g., try landing when using Landing Stats).

How do I update this addon?

Go to the addon's GitHub page, click on "userscript.js", copy the code, then go to Tampermonkey's Dashboard, click on the addon, press Ctrl+A (or Cmd+A on Mac) to select all, and paste in the updated code.

How do I know this addon is safe?

An easy way to check if a userscript is dangerous is to copy the code, paste it into an AI chatbot, and ask the AI, "Is this script safe? What exactly does it do?"
If you don't have access to AI chatbots (or don't trust them), some red flags to look for are:

  • Obfuscated code
  • URLs inside of code (specifically look for eval and fetch, and make sure those URLs are also safe)
  • Anything in the code that feels like it really doesn't belong to the addon
  • Long sections of random letters and numbers

When checking URLs to make sure they're safe, it would be best to use a burner device (a device that wouldn't cause you trouble if it were destroyed) and/or a VPN. If the URL shows nothing, that's a pretty big red flag. If the URL has code, check to see if that code is safe as well. If the URL is an image, it's probably safe.

I try to keep all code readable and (relatively) simple, so beginner programmers (and AI chatbots) can understand what the code does. I also try to make it clear and descriptive, and will never obfuscate or minify any userscripts.

Why is "track.tylerbialowas-bard.workers.dev" in some of the addons? What does it do?

As the comments above that chunk of code suggest, that URL is a Cloudflare Worker. Its main purpose is to track how many times people have loaded/reloaded GeoFS with that addon enabled in the last 24 hours and the last 30 days, and to keep track of how many "unique users" that addon has.
Most developers would call this "usage statistics", but when creating the Worker I thought of it as anonymous "tracking". It does not actually "track" you or store any info about you. I've been adding it to addons mainly out of curiosity (and so that if anyone asks how popular my addons are, I can actually give a good estimate).
I will never sell any collected data. I will never sell, share, or store any personal info, identifying information, or anything about you that's worth selling. If you don't believe me, or are still skeptical, you can always opt-out by following the instructions in the code.
I do not make any money from this. I also do not pay any money for this. There is no point in trying to overload the servers or fake information (and no, it's not funny, either).

In addons with automatic update notifications, there is also this line inside the checkForUpdates() function:
await fetch(`https://track.tylerbialowas-bard.workers.dev?event=${LSNAME}v${VERSION}`, {method: "HEAD"})
This lets me (and only me) know how long it takes people to update my addons.

If you want to see the statistics for yourself, go to https://tylerbmusic.github.io/stats, or view it unformatted at https://track.tylerbialowas-bard.workers.dev.
